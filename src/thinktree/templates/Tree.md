# {{title}}

- 📖 用法 & 图例
	- 节点 = 复选框：`- [ ]` 进行中 · `- [x]` 已定 · `- [-]` 否决 · `- [>]` 搁置
	- 写法：`- [ ] 问题 => 一句话结论`；节点下面的普通列表行是它的说明，`why:` 开头的那行（及其子条目）是 why
	- 子问题 = 缩进在下面的复选框；编号按位置自动生成，引用别的节点写 [编号]
	- 节点类型：标题开头写「实验：」或「思考：」，工具栏可以只看一类
	- 下面是示例，看懂格式后删掉，换成你自己的问题

## 起点：这个项目想回答什么（{{today}}）

- [x] 思考：这个项目到底想回答什么问题？ => 先用一句话写下来，后面每个分支都从这里长出来
	- why: 想得多了容易忘记当初为什么出发，所以第一个节点就是出发点
	- => 一句话版本：……（换成你的）
	- [ ] 思考：这个问题值得做吗？有没有人已经做过？
		- why: 动手前先确认不是重复造轮子
		- 链接 vault 里的笔记：在说明行里写 📄 加上 Obsidian 的双中括号链接
	- [-] 思考：方向 A，直接套用现成的方法 => 否决：前提条件对不上
		- why: 最省事，所以第一个想到
		- 否决的方向也留在树上，写清为什么，免得以后又绕回去

## 方法：打算怎么做

- [ ] ⭐ 思考：用什么数据？
	- why: 方法怎么选取决于有什么数据 ↔ [1a]
	- ⚠️ 前提：数据要能公开拿到
	- 标题前的 ⭐ = 重要节点；🚩 = 待办（查看器里选中节点按 x / t 也能加）
	- [x] 实验：先在小数据上跑通一版 => 能跑，但结果噪声很大
		- why: 先确认流程没问题，再花大钱跑全量
		- 实验节点记"做了什么、结果是什么"；从结果里想明白的东西，作为「思考：」子节点挂在下面
- [>] 实验：要不要再做一组对照实验？ => 搁置：等 [2a] 有结论再决定
	- why: 想到了但现在不急
